# 模块设计：桌面前端界面、Wails 外壳与发布流水线

## 1. 职责与边界

- **负责的事**：
  1. 严格按照 [前端设计.md](../前端设计.md) 与已验收原型，用 `React 19 + TypeScript (strict)` 实现无边框标题栏、左侧源列表栏、总览与出口（含 `实时 / 今日 / 近 7 天 / 近 30 天 / 按月` 流量图及 `按节点 / 按组织` 流量分布）、分流规则、规则集、实时连接与右侧检视器、设置页、右下角托盘面板与 `Ctrl+K` 命令面板。
  2. 封装 `frontend/src/services/daemonClient.ts`：对接守护服务真实接口，同步状态、执行切换出口、增删导入规则、挂载组织与导出脱敏配置。
  3. 提供 `cmd/singtail-desktop` Wails 桌面壳入口（无边框窗口、最小化隐藏至系统托盘、自动连接本机守护服务）。
  4. 提供 `scripts/remote-gate.sh` 一键门禁脚本与 `.github/workflows/release.yml` 自动化流水线，同时构建发布解压即用的绿色便携包（`.zip`）与 NSIS 标准安装包（`-setup.exe`）。
- **不负责的事**：前端不在本地自行拼装 `sing-box` 配置，所有业务写操作均通过守护服务接口落盘生效。

## 2. 结构与数据流

- `frontend/src/styles/tokens.css` & `desktop.css`：唯一设计令牌与低圆角线框样式源，业务组件禁止散落写死色值。
- `frontend/src/types/contract.ts`：与 Go `internal/contract` 1:1 对应的严格 TypeScript 接口。
- `frontend/src/state/selectors.ts`：流量单位格式化（`GB / TB`）、组织与节点占比计算、规则与连接关键字过滤纯函数（配 Vitest 单元测试）。
- `frontend/src/components/`：`SharpSwitch.tsx`、`SegmentedTabs.tsx`、`TrafficCanvas.tsx`、`ModalShell.tsx`、`TrayFlyout.tsx`、`CmdkPalette.tsx`。
- `frontend/src/features/`：`OverviewView.tsx`、`RulesView.tsx`、`ProvidersView.tsx`、`ConnectionsView.tsx`、`SettingsView.tsx`。
- `cmd/singtail-desktop/`：桌面窗口宿主（控制窗口最小化/最大化/隐藏至托盘并注入守护服务地址）。
- `.github/workflows/release.yml`：
  - `ci` 任务：每次 Push / PR 跑 Go 单测、前端 TypeScript 严格检查与 Vitest 单测。
  - `release` 任务：`v*` 标签触发，在 `windows-latest` 上编译 `singtail.exe` 与 `singtail-service.exe`，分别打包 `SingTail-windows-amd64-portable.zip`（含一键安装服务脚本与目录结构）和 `SingTail-windows-amd64-setup.exe`（NSIS 安装向导，自动注册服务并创建桌面快捷方式），上传至 GitHub Release。

## 3. 关键决策

- **严格遵守极简界面文案**：不设底部状态栏，不展示 `MTU`、DNS IP、内存占用、备注列与长句灰色提示，所有数据一眼可读。
- **前后端真实联调**：在 `cicd mac` 验收时直接启动真实 Go `singtail-service` 后端进程托管构建后的前端资源，验证真实 API 往返、SQLite 多粒度流量查询、超时自动回滚与规则导入落盘。

## 4. 当前实现

- `frontend/src/`：基于 `React 19 + TypeScript (strict)` 实现 `App.tsx`、五大业务视图（`OverviewView`、`RulesView`、`ProvidersView`、`ConnectionsView`、`SettingsView`）、通用低圆角组件（`SharpSwitch`、`TrafficCanvas`、`TrayFlyout`、`Modals`、`CmdkPalette`）、API 客户端 `daemonClient.ts` 及纯函数状态选择器 `selectors.ts`（含 13 条 Vitest 单测与异步请求版本号竞态保护）。
- `cmd/singtail-desktop/main.go`：内嵌 `frontendDist`，支持自动探测或自拉起本地守护服务、规范化监听地址，并以 WebView2 / Edge 独立窗口加系统托盘运行。
- `build/windows/installer.nsi` & `.github/workflows/release.yml`：CI 自动执行全量门禁，推送版本标签时自动构建并上传绿色便携包 `SingTail-windows-amd64-portable.zip` 与标准安装包 `SingTail-windows-amd64-setup.exe`。

## 5. 验证方式

1. 在 `cicd mac` 执行 `bash scripts/remote-gate.sh`：Go 检查与单测、Windows 双二进制交叉编译、TypeScript `strict` 检查、Vitest 单测、Vite 构建全部 0 错误通过。
2. 启动真实 Go 守护服务并通过浏览器代理完成端到端交互走查与实拍截图核对。
