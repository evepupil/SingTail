### 1.2 字体与字号阶梯

- **界面无衬线字族（`--font-sans`）**：`"Geist", "Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", sans-serif`
- **数据等宽字族（`--font-mono`）**：`"Geist Mono", "Cascadia Mono", Consolas, monospace`（全局开启 `font-variant-numeric: tabular-nums`，保证 IP、延迟、速率跳动时不抖动）
- **品牌像素字族（`--font-pixel`）**：`"Silkscreen", "Geist Mono", monospace`（仅用于左上角 `SINGTAIL` 标识）
- **字号阶梯**：
  - `10.5px`：大写等宽栏目标签（`letter-spacing: 0.08em`）、协议角标
  - `12px`：底部状态栏、表格内等宽参数、快捷键提示
  - `13px`：桌面端全局标准字号（左侧菜单、表格正文、按钮、输入框）
  - `15px`：卡片组标题、弹窗标题
  - `18px`：视图顶栏主标题
  - `24px`：核心遥测大数字（当前公网 IP、实时下行吞吐量）

### 1.3 间距、圆角与阴影阶梯

- **4px 基准间距阶梯**：`4px` / `8px` / `12px` / `16px` / `20px` / `24px`
- **极低圆角规范**：
  - `--radius-none: 0px`：主窗口网格、指标卡、数据表格、分段控制器外框
  - `--radius-sharp: 2px`：按钮、输入框、规则徽标、开关滑块、模态弹窗、托盘菜单
- **阴影规范**：普通平铺区块一律 `box-shadow: none`，完全靠 `1px solid var(--border-hairline)` 切分空间；仅悬浮层（模态弹窗、命令面板、托盘浮层）使用 `0 20px 56px rgba(0, 0, 0, 0.62)`。

## 2. 桌面窗口布局与尺寸自适应

采用桌面原生无边框应用骨架（`100vw × 100dvh`，外层不出现网页滚动条，仅内部列表区独立滚动）：

1. **顶部自定义窗口栏（高 `38px`）**：左侧品牌标识 + 服务运行灯；中部 `Ctrl+K` 全局检索框；右侧「托盘面板预览」按钮、明暗主题切换、Windows 标准窗口控制键（最小化 / 最大化 / 关闭）。
2. **左侧固定源列表栏（宽 `224px`）**：
   - 顶部常驻控制卡：TUN 虚拟网卡总开关 + `规则 / 全局 / 直连` 三段切换器 + 当前生效出口速览。
   - 中部五大主视图入口：`总览与出口`、`分流规则`、`规则集`、`实时连接`、`组织与设置`（激活项带左侧 `2px` `#CEFF00` 竖条）。
   - 底部协同栏：一键让路切换至 Clash Verge 按钮。
3. **右侧主工作台（自适应 `minmax(0, 1fr)`）**：
   - 视图顶栏（高 `48px`）：仅放视图标题与右侧操作按钮/筛选器，严格遵循最小必要信息原则，不堆砌副标题与废话说明。
   - 内容区：大于 `1100px` 时「实时连接」采用左表右检视器（`1fr + 340px`）双栏并排；窗口缩窄至 `760px～1100px` 时检视器自动折叠为底部抽屉面板，确保小窗口下表格不横向撑破。
4. **底部遥测状态栏（高 `28px`）**：展示虚拟网卡名与 MTU、本地混合监听端口、分流 DNS 状态、已加载规则总数与后台内存占用。

## 3. 基础组件六态与异常态画法

- **硬边按钮（`.btn-lime` / `.btn-hairline` / `.btn-danger`）**：
  - 默认：`2px` 圆角，`1px` 实线边框
  - 悬停（Hover）：主按钮亮度 `0.93`；线框按钮底色升至 `--bg-elevated`、边框升至 `--border-strong`
  - 按下（Active）：`transform: translateY(1px)`
  - 禁用（Disabled）：`opacity: 0.42; cursor: not-allowed`
  - 加载（Loading）：前置 `12px` 等宽旋转符（如核验公网 IP 时显示 `核验出口 IP…` 并锁定重复点击）
  - 错误（Error）：边框切为 `--status-red`，配简短原因条
- **空态 / 加载态 / 错误态统一规范**：
  - 空态：居中 `1px` 虚线内框，单行说明（如「无匹配规则」）+ 一个直接动作按钮（如「清空筛选」或「新建规则」）。
  - 加载态：行内脉冲暗纹骨架条 + 明确动作名（如「正在经出口核验公网 IP…」）。
  - 错误回滚态：顶部紧凑告警条（红框深底），直接写明实测结果与回滚动作（如「节点 us-west-relay 出口核验超时，已自动切回 GolfJoy Mac mini」）。
- **长文本溢出**：机器名、规则匹配值、进程路径统一开启 `text-overflow: ellipsis; overflow: hidden; white-space: nowrap`，悬停 `title` 展示全称，网格子项统一加 `min-width: 0`。

## 4. 动效与无障碍底线

- **动效时长与缓动**：状态切换与悬停 `120ms ease`；抽屉与模态框开合 `160ms cubic-bezier(0.2, 0.8, 0.2, 1)`；实时速率曲线每秒平滑推进一帧。
- **无障碍底线**：正文与数字对比度 ≥ `4.5:1`；所有按钮、模式切换、表格行支持键盘 `Tab` 聚焦，`:focus-visible` 显示 `2px solid var(--accent-text)` 内轮廓；支持 `Ctrl+K` 唤起全局命令检索、`Esc` 关闭任意浮层。
