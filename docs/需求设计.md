# SingTail 需求设计

## 1. 一句话定位

给拥有 Tailscale（组虚拟内网的工具）出口机器的用户，提供一个开箱即用的 Windows 桌面客户端：支持同时挂载多个 Tailscale 组织、自动列出组织内可用的出口节点（Exit Node，允许借它网口上网的远端机器）并一键验 IP 切换，自带精准国内外分流、可视化规则配置与实时连接分流台，彻底取代命令行脚本与难用的 `9090/ui` 网页看板。

## 2. 背景

现有本机脚本方案验证了一套极稳的网络底子：国内流量直连不减速、境外域名经加密通道查询真实 IP、与本机原有 Tailscale 客户端互不抢路由、切换出口自动核验公网 IP 并在异常时回滚。

但脚本方案依赖终端命令、手改 JSON 配置文件、手填出口 IP，新增组织出口还要手动起临时授权进程合并配置；内置的 `9090/ui` 网页看板面向百节点机场设计，不符合自建 Tailscale 出口直觉。因此需要立项 `SingTail` 桌面端，把交互彻底产品化并作为独立开源项目维护。

## 3. 谁在用

| 角色 | 怎么用 | 要什么 |
|---|---|---|
| 自建节点个人用户 / 开发者 | 海外云服务器、Mac mini 或家宽软路由开启 Tailscale 出口，电脑安装 SingTail 作为日常主力网络入口 | 点链接登录即用；国内软件和国服游戏直连低延迟，境外秒开；平时缩在右下角托盘静默运行 |
| 多组织切换用户 | 同时拥有个人账号与公司团队等多个 Tailscale 组织，跨组织切换出口 | 多组织同时在线挂载，所有可用出口机器汇总在同一列表里随点随切 |
| 进阶规则玩家 | 导入社区规则集、按软件或域名精调分流、遇到特殊站点切备用线路 | 界面点选运行中软件加规则、导入规则文件、订阅自动更新、一键让路 Clash 或走兜底外部代理 |

## 4. 名词解释

| 名词 | 含义 |
|---|---|
| 组织（Tailnet） | 一个独立的 Tailscale 虚拟内网空间（如个人空间、公司团队空间），登录后自动同步设备列表 |
| 出口节点（Exit Node） | 组织内开启了出口权限的远端机器，SingTail 将命中出境规则的流量经加密隧道交由它访问公网 |
| 直连打洞 / 中继（P2P / DERP） | 本机与出口机器之间是点对点直连（低延迟）还是经官方中继服务器转发（保底连通） |
| 分流规则 | 按域名后缀、关键字、软件进程名、IP 段或规则集决定流量「走出口」「直连」或「拦截」的匹配条目 |
| 规则集（Rule Set） | 编译或打包好的批量域名 / IP 名单文件（`.srs` / `.json` / `.yaml`），支持本地导入与订阅链接更新 |

## 5. 需求点

### 组织与出口节点管理
- 支持同时登录并挂载多个 Tailscale 组织（每个组织独立保存设备凭据，切换出口无需重新登录）。
- 自动发现并展示各组织下所有开启出口权限的节点（显示机器名、所属组织、Tailscale IP、在线状态、延迟、直连/中继状态）。
- 一键切换出口节点，切换后自动实测公网出口 IP，核验失败自动回滚至原出口并提示原因。

### 分流规则与规则集管理
- 内置开箱即用的默认分流策略：国内域名与国内 IP（含阿里云 `8.128.0.0/10` 修正段）直连，境外域名经出口走加密 DNS 解析并出境，本机私有网段与原生 Tailscale 客户端进程强制直连。
- 可视化编辑个人分流规则：支持按域名、软件进程名、IP 段、规则集新增、启停、调整优先级顺序和删除。
- 支持从「实时连接 / 运行中程序」列表直接一键把某个程序或域名加入「直连」「走出口」或「拦截」规则。
- 支持导入本地规则文件，以及配置在线规则订阅地址定时自动更新（替换前校验规则文件可正常解析）。
- 支持一键切换全局分流模式：规则分流、全局走出口、全部直连。

### 外部代理协同与兜底
- 支持「一键让路切换至外部 Clash 客户端」与「一键接管回 SingTail」，自动安全回收虚拟网卡防止抢路由断网。
- 支持配置一个外部备用代理出口（如本地机场端口），供云厂商 IP 受限的特定域名（如部分 AI 或流媒体服务）单独分流兜底。

### 深度自研桌面界面与系统集成
- 采用低圆角、高密度线框分割的原生桌面客户端界面（含无边框自定义标题栏、左侧导航栏、底部状态栏、快捷键检索）。
- 支持最小化至系统托盘（右下角小图标），托盘弹出面板可直接开关总引擎、切换分流模式、秒切出口节点与让路外部代理。
- 底层流量引擎以系统后台服务静默运行（开机免弹管理员框自启、关闭界面不断网、异常崩溃自动拉起）。
- 支持个人规则与设置的一键备份恢复，以及自动剥离私钥凭据的脱敏配置导出分享。

## 6. 非功能要求

| 维度 | 要求 |
|---|---|
| 平台范围 | 首版聚焦 Windows 10/11 桌面端深度打磨，底层数据结构预留跨平台扩展空间 |
| 安全与隐私 | 组织私钥凭据、规则缓存仅存本机；导出分享配置时强制剔除登录态与私钥目录 |
| 网络调优 | 默认启用虚拟网卡 `MTU 1280`、纯 IPv4 栈防空等、排除 `100.64.0.0/10` 网段、控制面直连解析防开机死锁 |
| 资源与磁盘 | 全程不修改 Windows 系统代理注册表；默认仅记录警告与错误日志，调试时按需开启实时连接流 |
