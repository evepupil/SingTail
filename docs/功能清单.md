# SingTail 功能清单

## 1. 组织与出口节点管理

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 1.1 | 多 Tailscale 组织挂载 | 支持同时登录多个 Tailscale 组织，各组织凭据分目录独立保存、互不覆盖 | 要 |
| 1.2 | 独立端口无损登录授权 | 新增组织在独立本地端口拉起授权链接，授权期间不中断当前虚拟网卡网络 | 要 |
| 1.3 | 出口节点自动发现 | 登录后自动拉取组织内所有开启出口权限（Exit Node）的机器、IP、区域及直连/中继状态 | 要 |
| 1.4 | 出口节点批量延迟探测 | 一键并发探测所有已发现出口节点的当前响应延迟 | 要 |
| 1.5 | 出口一键热切与公网 IP 核验回滚 | 切换出口后经混合端口实测公网 IP，超时或不符时自动切回上一可用出口并告警 | 要 |

## 2. 分流引擎与规则配置

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 2.1 | 默认最佳实践分流配置生成 | 自动生成含国内直连、境外加密 DNS、排除 `100.64.0.0/10`、修正 `8.128.0.0/10` 的内核配置 | 要 |
| 2.2 | 外部代理进程无感共存 | 内置自动直连放行 `tailscaled.exe`、`verge-mihomo.exe`、`clash-verge.exe` 防止抓包套娃 | 要 |
| 2.3 | 三档全局运行模式切换 | 支持「规则分流」「全局走出口」「全部直连」实时切换 | 要 |
| 2.4 | 可视化个人规则增删改排 | 支持按域名后缀、关键字、进程名、IP 段、规则集新增、开关、上下调整优先级与删除 | 要 |
| 2.5 | 点选运行中程序加规则 | 枚举当前电脑正在运行的进程列表，一键将其设为直连或走出口 | 要 |
| 2.6 | 本地规则文件校验导入 | 支持读取或粘贴外部规则文本（Clash / Surge / CSV 行），校验通过后批量置顶导入 | 要 |
| 2.7 | 本地外部代理转发走向 | 支持将指定规则流量转发至本地外部代理端口（如 `127.0.0.1:7897`）应对受限站点 | 要 |

## 3. 规则集与订阅管理

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 3.1 | 本地规则集列表与条目统计 | 展示本地 `.srs` 规则集清单、来源、规则条数与最近更新时间 | 要 |
| 3.2 | 远程规则订阅添加与安全更新 | 支持新增 `.srs` 订阅链接并手动/定时拉取，替换前校验二进制规则包格式合法 | 要 |

## 4. 流量统计与实时连接

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 4.1 | 实时吞吐采样与波形 | 每秒采集上下行速率，驱动总览与托盘实时速率展示 | 要 |
| 4.2 | 多粒度历史流量归档查询 | SQLite 存储近 48 小时细粒度采样并自动滚动聚合为「今日 / 近 7 天 / 近 30 天 / 按月」趋势与总量 | 要 |
| 4.3 | 组织与出口节点流量分布统计 | 按所选时间范围统计各 Tailscale 组织与各出口节点的累计流量及占比排行 | 要 |
| 4.4 | 实时连接流与右侧检视器 | 展示当前活动连接、进程、命中规则与延迟，支持在检视器内按域名或进程一键生成分流规则 | 要 |

## 5. 桌面外壳、托盘与备份

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 5.1 | 无边框低圆角桌面窗口与双主题 | 自定义 38px 标题栏、`Ctrl+K` 全局检索、暗色炭黑与亮色纸张主题切换 | 要 |
| 5.2 | Windows 系统托盘驻留与快捷面板 | 关闭窗口最小化至右下角托盘，支持托盘开关总引擎、切分流模式、秒切出口节点 | 要 |
| 5.3 | Windows 后台服务开机静默自启 | 注册系统级后台守护服务管理虚拟网卡，开机免弹 UAC 框静默启动、崩溃自动重启 | 要 |
| 5.4 | 脱敏配置导出与恢复 | 导出个人规则、订阅与常规设置 JSON，强制剥离所有 `ts-state` 组织设备私钥 | 要 |
