# SingTail Roadmap（开发路线图）

## 1. 项目目标

把原本依赖命令行脚本和手改 JSON 的 `sing-box + Tailscale` 高品质分流方案，打造成开箱即用的独立开源桌面软件 `SingTail`：支持多组织出口节点自动发现与验 IP 安全热切、可视化规则配置与文件导入、按日/周/月与按组织/节点的多粒度流量统计、与外部 Clash 无感共存，并通过 GitHub Actions 自动产出绿色便携包与标准安装包。
